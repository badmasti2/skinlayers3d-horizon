# 3D Skin Layers for Horizon

**Released — v0.1.0**

A native Horizon mod that gives your skin's outer layer a 3D pixel effect, adding depth to hats, jackets, sleeves and trousers. Supports classic and slim player models and player heads.

An independent Rust implementation inspired by 3D Skin Layers, created for Horizon.

## Source code

The mod's Rust source and mixin configuration are in [`mixins/skinlayers3d_horizon`](mixins/skinlayers3d_horizon). Mesh tests are in [`tests/mesh.rs`](tests/mesh.rs).
